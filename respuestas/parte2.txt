2. ¿Cuántos bucles for necesitas para recorrer todos los elementos de un arreglo 2D? ¿Por qué?

RESPUESTA:Se necesitan dos bucles for: uno para recorrer las filas y otro para recorrer las columnas. Esto permite revisar cada elemento de la matriz.

4. ¿Qué significa String.format("%-12d", valor)? ¿Qué cambia si quitas el -?

RESPUESTA:Sirve para mostrar un número entero ocupando un espacio de 12 caracteres y alineándolo a la izquierda. Si quito el signo menos, el número se alinea a la derecha.
